The whole internet in a single word: **brainrot**.

One word, funny on its own, true of the internet as a whole — an
endless feed engineered to rot your attention span, and we all keep
scrolling anyway — surprising (not the first obvious word anyone
reaches for), and short enough to land in one beat.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, standard library only) writes the word to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` outside the
grader sandbox). The word itself is also in [WORD.md](WORD.md).
